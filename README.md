# Brandon Byars official site

Live: https://brandowithabanjo.github.io/brandowithabanjo/

Official site of Brandon Byars: singer, songwriter, producer. GitHub Pages serves `main` from the repo root.

- `index.html`: the whole site (about, streaming links, *Last Call Carolina* tracklist, direct sales, press contact) with SEO tags and JSON-LD structured data
- `og-image.png`: 1200x630 share card for link previews
- `favicon.svg`: browser tab icon
- `sitemap.xml`: submit this URL in Google Search Console

When the address changes (custom domain or renamed repo), update every `brandowithabanjo.github.io/brandowithabanjo` URL in `index.html` and `sitemap.xml`.
